# RGB-D 几何验证

启动原有桌面图标，在第三个标签页 **RGB-D 几何验证** 操作。

## 多姿态样本集

1. 在上方 **多姿态样本集** 设置照片数量（1–100），点击 **创建姿态1～N**。程序自动命名各姿态，并提示需要拍摄的数量。
2. 当前为姿态1，点击 **开启相机预览**，摆好姿势后点击 **倒计时采集 RGB-D**。画面显示当前姿态编号和倒计时。采集完成后检查照片；若不满意可重拍，旧照片和结果仍保留。
3. 点击 **确认，下一姿态**，程序切换到下一张并开启预览。按同样方式完成全部照片。每张都有独立 RGB、同步深度、内参和点云。
4. 如需 SAM3，在姿态下拉框切换各张照片，分别点击 **人体前景点 ＋ / 背景点 −** 标点。状态显示前景/背景点数量；每张至少需要一个有效前景点，背景点用于排除误选区域。提示点立即保存，切换或重新打开不会丢失。
5. 点击 **SAM3 分割全部姿态**，程序先检查全部照片和标点，再释放人体/MHR GPU 模型。SAM3 只加载一次，依次分割全部姿态；进程退出后才应用候选掩膜并恢复人体模型加载。逐张检查，可切换候选、补点，再用下方单张 SAM3 按钮精修。取消批量分割时，已保存的候选会在进程退出后应用。
6. 在第一页设置启动方案，返回本页点击 **当前方案运行全部姿态**。程序应用并预热一次，再依次重建；有掩膜的样本自动评估，无掩膜只保存重建与耗时。不同静态姿态之间不应继承时间状态，因此批量任务要求关闭 **MLP 平滑和 One Euro**，SMPL 转换本身仍可使用。
7. 切换启动方案，再次点击批量运行。默认 **跳过已完成**：仅在启动配置、人物选择规则、RGB、深度/点云、内参和掩膜均相同时复用已完成结果；取消勾选可重新测试。任务失败会逐张记录，取消/退出保留已完成结果，重新打开样本集即可续跑。
8. 点击 **联合对照**，查看“姿态 × 方案”表格。可切换推理耗时、深度 MAE、点面 MAE、轮廓 IoU、覆盖率；点击格子载入对应点云/网格，关闭对照窗口后查看，切换同一姿态的方案会保留三维观察角度。每格取当前输入下最后一次完成结果。
9. 点击 **导出整组**，复制整组数据与 `pose_details.csv`、`pose_summary.csv`。汇总按姿态等权，并仅比较各方案共同有效的姿态；显示共同样本数、均值、中位数和最差值。缺失/失败/输入已变化的项单独标记，不当作零误差。

样本集保存在 `outputs/rgbd-sets/<时间>/`，索引文件为 `pose_set.json`，包括姿态顺序、当前照片路径、方案快照、任务进度和逐张失败原因。每张照片沿用下文单样本格式。使用 **打开样本集** 继续，使用 **退出样本集** 返回单张操作；退出不删除数据。更改掩膜会使对应旧评分失效，但不会删除旧预测与评估文件。

首版逐张由用户确认后再拍下一姿态，避免用户尚未准备好就自动拍摄。姿态集切换不要求重新安装模型或修改环境，继续使用现有显存互斥机制。


## 单张验证

1. 点击 **开启相机预览**，让头脚完整入画。选择倒计时，点击 **倒计时采集 RGB-D**；倒计时期间继续显示画面，到时保存同步 RGB-D 并自动释放相机。预览与拍摄使用同一相机进程，无需重新连接；也可直接倒计时采集。第一页若只有相机预览，会自动关闭并切换到本页；若正在实时推理，请先停止。活动流默认 RGB 1280×720、深度 848×480；实际配置与内参随样本保存。
2. 优先使用 **人体前景点 ＋ / 背景点 −** 在图中标点，再点击 **SAM3 自动分割**。绿区为人体掩膜；遗漏处补绿点、残留背景处补红点后重新分割。保留 **手工圈选（备用）/ 完成圈选 / 载入掩膜** 供人工修正与外部标注。详细步骤见文末。
3. **设置启动方案 / 预热** 返回第一页选择标准版/Fast、384/512、身体模式等，应用并预热后返回验证页。**用当前方案重建此样本** 使用冻结的 RGB 和该样本真实内参；勾选“掩膜框指定人物”时，以独立掩膜外接框为各方案共用的人物框，否则使用后端人物检测。
4. 生成网格后立即放入点云场景，随后自动评估。可旋转、缩放，切换正面/侧面，控制网格透明度、点大小、骨架和仅人体点云。表格选择旧行即可切换旧结果。
5. 更换启动方案并预热，再次重建 **同一个样本**，比较表格。更改掩膜后旧分数隐藏，旧评估文件仍保留；重新评估后比较同一掩膜的结果。
6. 导出完整实验包或保存场景截图。取消采集会释放相机；取消评估保留样本和原始预测。

## 坐标和标定

- 点云与网格均为彩色相机坐标：X 向右、Y 向下、Z 向前，单位米。
- 网格使用 `pred_vertices + pred_cam_t`。不单独居中、缩放、平移、ICP 或按深度拟合。
- 原始深度 `uint16 × depth_scale_mm / 1000` 得到米。使用真实深度内参和 Brown 畸变反投影、深度到彩色外参变换，投影进校正畸变后的 RGB；同像素保留最近 Z，不插值、不填洞。
- RGB 同样按活动 RGB 标定去畸变，保持相同 K。模型推理和评分均使用这套有效内参，不沿用其他分辨率的固定内参。
- SDK 开启帧同步，保存两帧设备时间戳与索引，只接受时间戳差不超过 20 ms 的帧。相同时间戳不等于已测得曝光同步误差，快速动作应另做时序验证。
- 预览点云按像素步长 2 抽稀；统计和 PLY 使用完整采样。骨架只是预测位置，不以表面贴合验证骨骼真实性。

## 分数解释

- 深度误差：真实相机视角前表面 Z-buffer 与独立人体区域内有效实测深度比较。正值表示模型更远，负值表示更近；报告均值、MAE、中位数、P90 和 <1/2/5 cm 比例。
- 热图 ±50 mm：蓝色更近、红色更远。灰暗区域无重合有效深度，不计入深度 MAE。
- 有效深度比例、模型覆盖率、完整轮廓 IoU 同时报告。小重合区的低 MAE 不代表整个人重建好。
- 点面距离：从掩膜内有效观测点固定随机种子均匀抽取最多 2000 点，计算到完整网格三角形表面的精确最近距离，报告 MAE/中位数/P90。这是单向观测点到表面距离，不惩罚未观测背面；其意义和相机视角 Z 误差不同。
- 单视角、衣服/头发、遮挡、标注、深度噪声和标定误差都会影响分数。它不是完整裸人体、关节旋转或内部骨骼真值。先拍摄贴身衣物、完整入画、静止姿势作为基线。
- SMPL 转换、仅关节点的 One Euro 不改变 MHR 原始网格，因此这些网格分数不能评估骨架滤波效果。
- 表中推理时间来自现有模型报告，RGB-D 采集、渲染、评估另行执行，不能当作实时全流程帧率。

## 文件

`outputs/rgbd/<样本时间>/`：

- `rgb_raw.png` / `rgb.png`：原始 RGB / 校正后的推理 RGB。
- `depth_raw.png`：无损原始 16 位深度，比例在 `camera.json`。
- `rgbd.npz`：配准后的 `depth_m` 和有组织 `xyz_m`，无效位置为零。
- `camera.json`：活动流、设备、内参、畸变、D2C 外参、深度比例、时间戳和配准方法。
- `scene.ply`：真实米制彩色场景点云。
- `mask.png`：当前独立人体掩膜。旧评估自带当时掩膜与 SHA256。
- `predictions/<时间>/`：原始预测 NPZ、启动请求和推理报告（包含资源校验记录）。
- `evaluations/<时间>/`：`metrics.json`、相机系人体 PLY、人体观测点 PLY、深度热图、观察/渲染深度数组及抽样点面距离、掩膜、日志。
- `results.json` / `comparison.csv`：方案对照索引和汇总；掩膜哈希不同的记录不可直接比较。

旧的仅 RGB Studio 照片没有对应深度，不能直接导入本页进行真实深度验证。当前支持读取上述完整实验包目录。

## 相机预览

预览以约 10 FPS、800 像素宽的非镜像彩色画面显示，方便摆姿势；最终保存仍是相机完整分辨率，且沿用原有真实标定、帧同步与深度配准流程。预览不建立样本目录、不保存图片或视频，也不修改已打开样本的提示点和掩膜。点击 **关闭相机预览** 或 **取消** 后，恢复原样本显示并释放设备；关闭 Studio 同样会停止相机。预览期间禁止标点、分割与评估，拍摄结束后恢复。预览使用原始彩色流，保存的 `rgb.png` 会校正畸变，因此边缘可能有轻微变化。

## SAM3 前景 / 背景点分割（优先使用）

无需沿人体轮廓手工描边。在 RGB 图上点击 **人体前景点 ＋**，在躯干及需要保留的手臂、头部等部位标少量绿点；点击 **背景点 −** 标记桌面、手机、人物之间的空隙等误选区域。鼠标右键始终添加背景点；支持撤销和清空提示。

点击 **SAM3 自动分割（先释放人体模型）** 后：

1. 仍在人体重建/实时流时拒绝启动，请先停止当前任务。
2. 自动释放当前标准版/Fast 常驻模型及 MHR 实验室 GPU 模型，取消待执行的自动重载，等待其进程完全退出。
3. 使用 `config/local.json` 中的 `sam3_python`、`sam3_repo` 与 `sam3_checkpoint`，以 BF16 autocast 执行 SAM3 原生图像点提示分割，不安装或改变原环境，不下载权重。
4. 返回多个候选掩膜，优先选择满足提示点最多、其次预测质量分最高的结果。可在候选框切换，或补充红绿点后重新分割。每次分割完成都退出 SAM3 进程，不让它常驻显存；结果仅在进程退出后应用。
5. 确认绿色覆盖区域后，返回第一页选择方案并预热人体模型，再重建同一样本。再次分割将再次释放人体模型，不能让两个大型模型同时驻留。

除按钮状态和函数入口检查外，SAM3、标准版/Fast、MHR GPU 后端还使用同一个操作系统文件锁。SAM3 独占，与人体/MHR GPU 后端互斥，其他 Studio 窗口也不能绕过；异常退出时锁由系统释放，编译子进程不继承锁。CPU MHR 不占用此锁。这个机制不控制其他独立应用；SAM3 加载前还会检查当前空闲显存，低于 5 GiB 时拒绝加载，不会擅自关闭其他程序。

提示点保存在 `sam3_prompts.json`；每次分割候选、运行报告、请求与日志在 `segmentations/<时间>/`；接受的掩膜仍保存为 `mask.png`，其来源和选择写入 `mask_source.json`。评估按掩膜 SHA256 区分，旧掩膜的分数不会伪装成新掩膜分数；实验包包含这些材料。更换候选或重新分割后需要重新评估。

SAM3 的“预测质量”不是实测人体分割 IoU。自动掩膜仍需检查遗漏、手持物、衣物和遮挡边缘；它独立于待评估的人体重建模型，但仍不等于人工真值。

## 历史项详情、删除与双项对比

在底部“配置 / 时间”历史表中右键一行：

- **展示详细配置**：读取该次保存的完整启动配置、实际编译 / TensorRT 状态、预热、模型推理 / 工作进程到网格 / GUI 网格就绪耗时、评估指标与资源校验信息。双击一行也可打开。旧记录缺失的字段显示“未记录”，不会拿当前界面设置补齐。
- **与另一项进行详细配置及推理等信息对比**：右键行作为 A，从下拉列表选择 B。配置与执行 / 指标差异高亮，可勾选“仅显示有差异”；数值差值为 B−A。输入图片、人物框、相机内参、掩膜或批处理指纹不一致 / 不完整时会提示，历史掩膜指标不会被当成当前掩膜指标。单次时间不能代表稳定帧率。
- **删除该项**：从当前历史索引及 CSV 中移除，刷新当前样本集汇总。原始预测、推理报告和评估文件继续保留；删除前索引备份位于样本目录 `history-trash/results-<时间>.json`，其中 `results` 数组可用于人工恢复 `results.json`。这不是清理磁盘功能。批处理、分割、推理或相机采集期间禁用这些历史操作。

详情 / 对比窗口的“模型 / 误差图对照”标签按点击加载已保存网格，不加载推理模型。双项模式下旋转 / 缩放任一侧会同步另一侧，也可统一正面或侧面。模型沿用原始相机坐标和尺度，误差图来自各次历史评估。原始记录 JSON 可查看、复制，便于追溯未列出的字段。
