# 离线视频多人重建

“视频重建”是独立标签页，使用本页启动方案，不修改第一页设置。导入视频后保留原文件，在 `outputs/video/<任务>/` 保存解码帧、逐人掩膜和多次运行结果。需要 FFmpeg/ffprobe，以及配置好的 SAM3、标准版或 Fast 环境；合成网格使用标准版环境的 pyrender/EGL。

## 操作

1. 停止其他页面相机/推理，释放第一页与 MHR 实验室 GPU 模型。导入视频；或打开已有任务继续。
2. 新增人物，移动到该人物出现的帧，左键添加人体前景点，右键添加背景点。设置终点帧，点击“保存当前帧提示”。对其他人物重复操作，人物 ID 相互独立。
3. 点击“① SAM3 分割”。跟踪按人物、分段依次运行，有界保存 32 帧跟踪历史，状态卸载到 CPU。阶段退出后才允许人体模型加载。
4. 在时间轴逐帧检查选中人物的绿色掩膜。失跟、切镜或遮挡后需要重新初始化时，到对应帧重新点选并保存；前一段自动截断到此帧之前。可删除无效分段。修改提示后需重新分割。
5. 展开本页启动方案，选择标准/Fast、分辨率和编译选项，必要时调节掩膜膨胀/腐蚀；点击“② 应用本页方案、预热并逐帧重建”。同一帧多人复用一次 YOLO-Pose 检测，按掩膜匹配框，保留 YOLO 手腕提示；匹配歧义会记为失败。
6. 选择运行记录与“网格/骨架/网格＋骨架”，点击“③ 合成视频”。随后打开导出视频；也可勾选渲染帧预览，拖动时间轴检查。运行记录的工具提示包含完整配置。不同方案复用同一套 RGB 和掩膜，原始预测分别保留。

提示点需要点击保存；切换帧不会自动保存未提交的点。人物进出可以用分段范围限定；空掩膜记为不可见，重建失败帧保留原图并标注失败 ID，不沿用上一帧模型。只重建已添加且有有效分段的人物，不自动为所有路人建立 ID。

## 结果和恢复

```text
outputs/video/<任务>/
  project.json                  # 视频 SHA、时间戳、人物和分段提示
  frames/000000.png             # 原始 RGB 解码帧
  masks/person-001/<分段指纹>/   # 二值掩膜和 complete.json
  requested-config.json
  runs/<方案指纹>-<输入指纹>/
    config.json                 # 此次冻结配置
    worker.log
    faces.npy                   # 拓扑仅保存一次
    predictions/<帧>/person-001/
      prediction.npz            # 数值数组，禁止 object pickle
      result.json               # 成功/失败、推理时间、人物框、相机内参
    run.json                    # 输入和方案指纹、成功/失败统计
    render-mesh/                # 渲染帧
    overlay-mesh.mp4            # 合成视频（可另选 skeleton/both）
```

取消后等待进程退出；再次启动复用完整分割段和成功的人物帧，失败帧会重试。修改分段、方案或形态半径产生新运行目录。分割阶段中断后该段重新跟踪，不从不完整时序状态续接。导入解码中断可重新导入；尚未生成 project.json 的目录不作为可恢复任务。

数据管理页面按整个任务统计和移入回收站，当前打开任务受保护。原视频不复制，保留音频需要它仍在原路径。输出核对帧数、时长和音轨；可变帧率输入按原始显示时间戳合成。渲染 PNG 较占空间，可通过数据管理清理完整旧任务。

## 首版边界

- 视频使用默认图像焦距估计；不会套用 Gemini RGB-D 相机内参。人物间距离和绝对尺度未经标定，不等同于真实相机下的多人几何关系。
- 保留原始逐帧输出，暂不启用 One Euro / MLP，以免人物共享时序状态。SMPL 转换可选；网格抖动、快动作和重遮挡仍可能存在。
- 掩膜跟踪辅助人物选择和网络提示，不能保证身份永不交换。请检查分段和合成结果。
- 网格之间按预测深度互相遮挡，原图中的桌椅/未重建人物等不提供真实深度遮挡。重建不能恢复精确衣物细节。
- 人体、SAM3 和视频渲染阶段使用跨进程显存互斥锁；对不使用 Studio 锁的外部程序不生效。批处理期间保留所有原始帧，不提供实时性能承诺。
- 不把输入视频、模型、环境或运行数据加入 Git。原始视频的使用及分享权限由使用者确认。
