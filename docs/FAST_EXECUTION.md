# Fast 最终预测图重放与身体推理执行优化

2026-11-08。目标是降低 Gemini 336L 实时流中每帧的 Fast 推理耗时，不改变相机采集、GUI 排队或渲染行为。单图、视频和实时流共用 `studio/body/fast_worker.py` 中的 `forward()`，因此该后端优化同样应用于实时流。

## 最终完整人体预测

`fast_execution.FinalBodyReplay` 包装已编译的完整身体预测核心（姿态 head、完整 MHR、相机与投影），在预热时用独立流捕获 CUDA Graph。每次重放前更新九个张量输入，保留相机主点选项作为图签名的一部分；相机内参、裁剪尺寸或输入内容变化都不会复用旧数值。所有 19 个输出张量复制到独立存储，防止输入视图或上一帧结果被后一次执行覆盖。

仅无梯度、单人 CUDA、已编译身体模式默认启用；CPU/其他 batch/不支持的调用布局走原核心。Studio 完整手部模式不默认启用此图重放。保持完整 18,439 顶点、127 骨架和其他输出，保持模型权重、数值精度、分辨率及中间反馈次数。

## 同步和数据搬运

通过检查过的原方法 AST，在本实例生成身体模式专用版本，替换点限于 `process_one_image`、`run_inference`、`forward_pose_branch` 中独立语句形式的 `print()`、分段计时 `torch.cuda.synchronize()` 和每帧 `empty_cache()`。不重写神经网络数学操作、检测/裁剪逻辑、异常抛出、输入检查或流依赖，不修改上游文件，也不替换全局 torch 函数。

保留原有结果/提示缓存重置；取消 `empty_cache()` 不等于保留上一帧预测，仅允许 PyTorch 内存分配器复用空闲显存。

CPU 输出只传输原输出组装代码实际访问的字段。按 device/dtype 合并 CUDA 张量，异步复制到本次独占的 pinned CPU 存储，统一记录完成事件并**等待事件完成**，然后才允许 NumPy 读取。保留原来的全部公开结果字段。后一次传输不复用前一次返回给调用者的 CPU 存储。

优化仅在无梯度、身体模式、无额外 FOV 模型、未开启中间详细计时时使用。其他情况使用原方法。完整手部模式的多流依赖不纳入本次同步删减。外层 worker 仍在完整推理边界等待 CUDA 完成，计时不会因提前返回而虚降；边界后的有限值/形状检查仍保留。

运行时 AST 从用户已安装的上游函数生成，而非将整个上游文件复制进仓库。报告记录三个原方法的 SHA-256；来源为依赖清单中固定版本 Fast 的 Meta 继承代码。适配器按 SAM 许可单独标注。

## 使用与回退

正常 GUI 只需释放模型，再应用并预热当前 Fast 身体方案，不需要转换引擎。`ready` 与单图 `inference.json` 的 `execution` 记录两项状态、最终图是否实际捕获、方法来源哈希。

- `BODYSTUDIO_FINAL_REPLAY=0`：只关闭最终完整核心图重放。
- `BODYSTUDIO_BODY_IO=0`：只关闭身体模式的同步/搬运优化。
- 两项都关闭：回到上一轮 MHR70 专用路径＋反馈缓存的基线。

优化的是每帧都完整执行 SAM 网络的路径，并非上一帧姿态细化跟踪。不会将初始化耗时摊薄后当成推理提速。

加载器仍为本机既有 `/home/hzb/Work/fast-sam3d-body-deploy/run.py`；正式 Studio 不依赖这个外部诊断入口。原始报告、被测适配器快照及配对输出均在已忽略的 `outputs/`。`--stream-smoke` 使用已录制 Gemini 图像经过正式 stream 命令，验证连续推理协议，不是实时相机或显示帧率测量。

## Fast384 正式复测

RTX 4060 Laptop 8GB；384 身体模式；骨干/YOLO TensorRT；解码器/MHR/中间预测编译；三次反馈。两边都保留上一轮反馈缓存和 MHR70 图重放。各预热10次，交替正式测量各240帧。

| --- | ---: | ---: |
| 完整推理均值 | 57.443 ms | 53.820 ms |
| 完整推理中位数 | 56.903 ms | 53.701 ms |
| 完整推理 P95 | 60.992 ms | 55.668 ms |

完整推理节省 **3.623 ms（6.31%）**。不能与历史不同运行的60.38ms直接相减。本轮额外四路消融各120帧：基线57.740、只开最终图55.851、只开执行优化55.841、两项启用54.073 ms；收益不能机械相加。首轮各80帧复测为58.346→54.267ms。

13张图及反馈次数/掩膜/内参对照，最大单坐标差：顶点0.001878 mm、70点0.001818 mm、127骨架0.001788 mm、相机平移0.003338 mm；二维投影0.013916 px，旋转矩阵元素0.000002965。这些是相对旧输出的浮点差异，不是人体真实精度误差。最终图换参数后生效、先前GPU输出未被覆盖；混合dtype的CPU传输逐值一致、前一次CPU输出保持不变。

原始结果：`outputs/profiling/execution-384-final-20261108/`；首轮：`outputs/profiling/execution-384-first-20261108/`。每个目录保留实际被测 `fast_execution-tested.py` 和配对NPZ。
