# Fast 中间关键点专用路径

2026-11-08，Studio 运行时适配 `studio/body/fast_keypoints.py`，不修改上游源码、模型权重和 TensorRT 引擎。正式后端 `studio/body/fast_worker.py` 在权重加载后、预热前安装。

## 计算范围

中间反馈只需要原定义的 70 个关键点。对本机经过验证的 MHR 回归矩阵，前 70 行的全部非零系数精确依赖 468 个表面顶点和 50 个骨架节点。原路径生成 18,439 个顶点和 308 个地标；专用路径将体型/表情基、蒙皮影响项和回归矩阵缩减到所需部分，不阈值化系数，不把 70 个关键点误当成前 70 个骨骼。

全部 127 个骨架节点仍参与参数映射和父子变换，确保祖先链完整；蒙皮沿用已加载 MHR TorchScript 中的原运算，仅将影响项从 51,337 个裁剪到 1,347 个。保留相同的手部参数置入、尺度、单位和坐标约定。

只裁剪顶点的第一版未带来整帧加速：同轮均值 62.904→64.600 ms，三次中间核心合计 8.065→7.998 ms，说明骨架运算的调度开销仍大。因此默认版本还将**单人的这段几何计算捕获为 CUDA Graph**，复用执行图，不复用上一帧数值。每次都复制当前体型、姿态及表情参数进固定缓冲区，再执行图。输出复制到独立存储，避免下一层或下一帧覆盖早先的反馈。

最后一次预测仍走上游完整路径，输出 18,439 顶点、127 骨架以及原有其余数据。六层解码器、反馈次数、70 点定义和数值精度设置保持原配置。没有删减姿态自由度或训练新网络。

## 生效条件与回退

- Fast 的身体中间预测必须启用编译和上游 slim 路径，且至少保留一次中间预测。单人 CUDA 输入使用图重放；CPU/其他 batch 使用普通紧凑运算。
- 最后一次预测、手部专用 head、启用 pose correctives、训练或有梯度时调用上游原实现。未编译或无中间反馈的方案不会触发此加速。
- 标准版后端不受该适配影响。完整手部精修性能本轮未验证。
- `inference.json` 与 ready 事件的 `keypoint_path` 记录开关、版本、依赖数量、单人图重放策略、实际是否已捕获 `graph_captured` 和配置适用性；`eligible_config` 表示该启动配置可走此路径，不是逐调用计数。
- 设置 `BODYSTUDIO_KEYPOINT_PATH=0` 启动 worker 可回退原完整中间路径。原反馈缓存独立保留；它的关闭开关仍为 `BODYSTUDIO_FEEDBACK_CACHE=0`。
- 已加载的 worker 需要“释放模型 → 应用并预热”。不需要重新转换 384/512 TensorRT 引擎。第一次使用专用路径包含编译与图捕获，预热之后才比较耗时。

## 验证方法

`tests/test_fast_keypoints.py` 对照本机原始 MHR，检查精确非零支持、原蒙皮缓冲区未修改、批量 1/2、体型/表情/姿态变化以及回退条件。GPU 基准在已安装反馈缓存的同一模型上交替开关专用路径，两边都保留此前反馈缓存优化，因此本次增益不重复计算上一轮节省。

每种路径预热 10 次，按 ABBA/BAAB 顺序交替测试。完整推理包含检测、裁剪、网络、CPU 输出，排除加载、文件读写、GUI、渲染和导出。中间核心和解码器的 CUDA 事件分项另行插桩；包含主机调度及流空隙，不能当作纯 GPU 核函数活跃时间，也不宜与整帧时间直接相减。

数值检查覆盖原测速图＋12 姿态集、3/2/1/0 次中间预测、掩膜及相机内参切换。另检查图重放使用新输入并且不覆盖先前返回值。这里衡量的是相对原路径的输出变化，不是相对真实人体的准确率。

```bash
python -m unittest discover -s tests -p 'test_fast_*.py' -v
python scripts/benchmark_fast_keypoints.py --image IMAGE.png --output outputs/profiling/NEW_DIR --poses POSE_SET --runs 60
# 512 兼容性测试：增加 --image-size 512
```

基准脚本沿用本机既有验证加载器 `/home/hzb/Work/fast-sam3d-body-deploy/run.py`，正式 Studio 不依赖该外部诊断脚本。请在 Fast Conda 环境下运行；GPU 测试使用 Studio 的独占模型锁。原始报告、源代码快照及逐图双份 NPZ 位于已忽略的 `outputs/profiling/`，不会发布真人数据或权重。
