# 独立 RGB-D 姿态采集

这是深度约束开发的第一个里程碑：先采集可重复使用的静态姿态集，再自动比较原始和深度校正结果。记录器只打开 Gemini 336L，不加载 SAM3、SAM 3D Body 或 Fast 模型，不运行分割和重建。

## 启动与拍摄

```bash
./launch_rgbd_recorder.sh
# 也可以直接继续之前的采集
./launch_rgbd_recorder.sh --session /path/to/recording-session
# 可选：安装独立桌面图标（不会替换 Studio 图标）
python3 scripts/install_desktop.py --recorder --desktop
```

1. 关闭 Studio 或其他程序中的相机预览。相机只能由一个采集进程使用。
2. 设置姿态数量，点击“新建采集”。左侧显示姿态清单和建议，可修改当前姿态说明。
3. 点击“连接相机”。上方为彩色，下方为深度伪彩；深度黑色区域没有有效测量。
4. 设定倒计时，摆好姿势后点击拍摄。Ctrl+Enter 拍摄，Esc 停止并释放相机。
5. 如需一人完成整组：勾选“自动依次拍摄”，设定换姿势间隔。程序从当前姿态依次拍到最后一张，每张先留出换姿势时间，再倒计时。
6. 提示保存成功后才算完成。重拍会创建新目录，旧版保留；中断后可“继续已有采集”。

自动采集在每张之后释放相机、导出数据，再为下一张重新连接。换姿势间隔从下一张相机就绪时开始，因此实际照片间隔还包含保存、重连和倒计时。这是离散 RGB-D 快照集，不是高帧率连续 RGB-D 视频。

拍摄期间不要在 Studio 中同时修改同一个姿态集。记录窗口会锁住这组数据，Studio 数据管理页禁止清理；关闭窗口或进程退出后系统会自动释放锁。

## 建议的一组数据

默认八个建议姿态：正面自然站立、双臂平举、双臂前伸、双肘弯曲、左右各转约45度、单臂抬高和侧身。可设置任意 1–100 张。

- 先拍摄双臂与躯干分离、无遮挡的基础姿态。
- 再拍摄双手靠近身体、双臂交叉和侧身等难例。
- 同一姿态可在两个距离重复拍摄，并把距离写入说明。
- 每张拍摄时保持静止、全身入画。避免截掉手腕、脚和头顶。
- 深度有效比例是整幅图像统计，不能当作人体区域深度质量或骨骼精度。

## 保存位置和内容

默认目录：`outputs/rgbd-sets/recording-<时间>/`，整个目录被 Git 忽略。

```text
recording-<时间>/
  pose_set.json                 # 当前姿态、说明、当前样本、重拍历史
  .recorder.lock                # OS 锁；文件保留不代表进程还在运行
  samples/
    pose-001/<拍摄时间>/
      rgb_raw.png               # 原始彩色
      rgb.png                   # 去畸变彩色，后续模型输入
      depth_raw.png             # 原始 uint16 深度；单位比例见 camera.json
      rgbd.npz                  # depth_m / xyz_m，配准至彩色相机，单位米
      camera.json               # 内外参、畸变、深度比例、帧号及时间戳
      depth_preview.png         # 仅预览，不能作为真实深度输入
      scene.ply                 # 相机系点云
      worker.log                # 相机采集日志
```

RGB-D 样本使用 `studio_rgbd_v1`，姿态集使用已有 `studio_pose_set_v1`。在 Studio 第三个标签页的“打开样本集”选择整个采集目录即可；也可以“打开已有样本”选择单张拍摄时间目录。之后再逐张标注 SAM3 前背景点、分割人体并批量运行。

仅完整导出、退出码为零且 RGB-D 时间差符合记录阈值的样本会加入当前姿态。取消或失败时不替换旧照片。未完成的目录可在确认不用后通过数据管理清理整个样本集，或手动处理。

## 后续开发边界

本里程碑没有修改网络、TensorRT、MHR 姿态，也没有执行深度校正。后续顺序：

1. 用此数据集测试三维平移校正，保留原始与校正结果。
2. 增加 GUI 对照、留出点检查、批量指标及独立求解耗时。
3. 证明收益后研究体型标定、双臂姿态精修与同步实时 RGB-D。
