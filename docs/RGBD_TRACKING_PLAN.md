### 可见内容与评价范围

- 抬臂、交叉屈肘适合测肩肘跟随、动作滞后和静止抖动。高举手臂时手部接近或越出上边缘，应单独标记可见性。
- 转身与移动包含侧身和距离变化，适合测根位置、朝向及肢体遮挡。
- 遮挡与恢复包含近距离局部裁切、完整出画和返回，适合测 LOST / REINITIALIZING 状态及恢复时延。出画帧不应强行输出正常人体或计入普通可见表面 MAE。
- 四组为单人、固定场景的短序列，足够支持第一版实验；不能代表多人、快速运动或长期漂移性能。
- 衣物表面与 MHR 人体表面存在差异；深度 MAE 是可见表面一致性，不是骨架关节真值。

## 推荐算法

采用“完整初始化 + 少步连续细化 + 轻量 RGB 引导 + 按需重初始化”。先不训练新网络。

### 初始化

1. 从首个合格且全身可见的帧初始化，默认使用 Fast384 身体模式和现有 TensorRT / 编译缓存。
2. 执行 SAM 3D Body 与 CUDA60 深度校正，取得较好的初始参数和相机位置。
3. 本段固定体型、骨长/缩放、表情与手部自由度；优先更新现有 25 个选中姿态参数和 3 个平移量。25 个姿态参数包含 3 个根旋转和 22 个身体参数。
4. 保留 Fast 当前 correctives=False 的定义，避免在跟踪中更改网格生成规则。Standard512 作为后续质量对照。

### 每帧跟踪

1. 按真实时间戳回放，先试 10 Hz，再试 15 / 30 Hz。10 Hz 约 0.1 秒一步，不能拿 30 Hz 的三分之一运动间隔代替目标测试。
2. 用上一帧参数初始化；在基础方案稳定后试带限幅的恒速度预测。旋转需处理环绕，角度/位移增量上限按真实 Δt 调整。
3. 复用已有 YOLO-Pose TensorRT 获取人物框与 17 个 2D 关键点。现有 `fast_selection.py` 和 `fast_worker.py` 已保留这些输出，不需要另换关键点模型。核对身体关键点语义映射和置信度后用于跟踪。
4. 将当前深度、当前 RGB 关键点与预测人体对齐。常规帧试 5 / 10 / 15 步，残差较高时最多 30 步；超过预算或明显失败则请求重初始化，不无界增加迭代。
5. 用当前残差、覆盖率、关键点置信度和参数跳变判断是否接受。静止帧可以保持原解，不能要求每一帧都至少改善 0.5 mm 才算成功。

建议目标函数：鲁棒点到面深度误差 + 少量点到点误差 + 置信度加权的当前 RGB 身体关键点重投影误差 + 弱时间先验 + 原生关节边界。

**不能原封不动复用单帧的关键点约束。** 当前 `baseline_uv` 是输入初值投影。把上一帧直接当本帧固定目标会抑制真实动作，产生滞后。跟踪应改用当前 YOLO 观测；遮挡点降权，用时间先验短时维持，不将补全结果当作观测。

### 深度计算提速

现有 CPU 法线估计、KD-tree、全分辨率渲染和接受检查仍有明显开销。仅少跑几步不能保证低于 100 ms。

- 只处理人体 ROI，在较低的几何分辨率构建深度/法线金字塔。此分辨率与 SAM 的 384/512 网络输入无关。
- 优先实现 GPU 投影对应：从投影位置查询当前深度，结合可见性、法线方向、距离与深度边缘筛选；避免每帧全图 KD-tree / PCA。
- 原始深度是有组织的网格，可先估法线再变换到彩色系。彩色全分辨率的最近 Z 配准较稀疏，不能对孔洞直接求差分法线；低分辨率几何格保留真实测量，不凭空补深度。
- 缓存固定体型、拓扑及 CUDA Graph；阶段性更新对应，保留必要的 CPU/GPU 往返计时。
- 每帧只执行一次有界接受检查，额外反复回溯留给困难帧。保留原全分辨率评估作为离线对照。

### 状态和恢复

状态：INITIALIZING → TRACKING → DEGRADED / LOST → REINITIALIZING → TRACKING。

- 正常：少步更新，输出参数与置信度。
- 部分遮挡：只约束可见部位，降低不可见关节的可信度。
- 完整出画：进入 LOST，停止将旧人体标为有效跟踪；不向空背景拟合人体。
- 返回：人物检测稳定后重新执行 SAM 初始化，校验身份/位置连续性再恢复。
- 首轮试验按 0.5 / 1 / 2 秒最大关键帧间隔及残差触发组合比较。阈值由这些序列标定，不提前宣称某个间隔最优。

## SAM3 与显存安排

### 第一版离线对照

先用现有 SAM3 视频传播，给每段准备人体掩膜。首帧点前背景；返回段若传播失效，再增加分段提示。将分割作为独立任务执行，结束并退出 GPU 进程后才加载人体模型。允许空掩膜，保留可见性状态和分割失败标记。

RGB-D 是原始彩色网格。先去畸变得到本轮模型使用的 RGB，再在相同网格分割，深度按相同内参配准。不能将原始图上的掩膜直接用于去畸变图。

离线分割、缓存关键帧推理可用于算法对照，但成本必须单列。不能把预先生成的掩膜、SAM 参数和配准数据都当作免费输入后宣称在线 10 Hz。

### 后续在线验证

采用一个跟踪 GPU worker 管理 YOLO、SAM 和 MHR。只获取一次独占锁，SAM3 不常驻；复用模型中的 MHR 资源，先验证 8 GB 下的显存峰值。现有离线 fitter 的 exclusive 锁与单独 body worker 不可直接同时启动，`fast_worker.py` 顶层也会加载模型，不能直接导入它再获取第二把锁。

实时人体区域另测试投影 ROI、YOLO 框与深度门限。若依赖离线 SAM3 掩膜才能稳定，应明确该结果仍是离线受控试验。关键帧推理造成的延迟尖峰必须保留；长时任务使用最新帧调度，避免无限积压旧帧。

## 四组上的对照与验收

先冻结输入、标定、掩膜和时间戳，按完全相同的抽帧规则比较：

| 方法 | 用途 |
| --- | --- |
| 每帧 Fast384 原始 SAM | 速度、抖动和漂移的基础对照 |
| 每帧独立 CUDA60 | 表面拟合质量参考；不是骨架真值 |
| 上一帧初始化 + 5/10/15 步 | 检查时序初值是否足够好 |
| 上述方案 + 当前 RGB 关键点 / 恒速度 | 分开验证 RGB 引导、运动预测的贡献 |

单帧减少到 15 步曾导致误差上升；不能假设跟踪就一定解决。须在本次连续输入上实际测量。

输出：逐帧参数、网格/骨架、时间戳、状态、置信度、关键帧原因、阶段耗时、深度 MAE/P90、分割参考 IoU/覆盖率、RGB 关键点残差及视频对照。掩膜为分割参考而非人工真值；关键点若用于拟合，其残差也不是独立精度证据。

分别统计静止、运动、部分遮挡、出画、返回；静止段统计抖动，运动段检查滞后与漂移；丢失段统计误跟踪，返回段统计恢复时延。表面拟合不能验证深度不可观测的骨骼轴向旋转。

速度同时报告核心拟合、原始 RGB-D 到跟踪输出、含显示的延迟；冷启动单列。必须包含解码、去畸变、配准、YOLO、拟合、接受检查、实际重初始化事件，报告中位数 / P95 / 最坏值和积压帧龄。10 Hz 是端到端目标，目前尚未验证。

## 开发顺序

1. **离线时序原型**：读四组 → 掩膜/基线准备 → 上一帧初值 + 少步更新 → LOST/恢复 → 导出视频、参数与指标。先用双臂抬放，再交叉、转身、出画。
2. **收紧计算预算**：当前 RGB 关键点约束、GPU 深度预处理与投影对应、共享 worker、完整计时。依据实际结果决定关键帧间隔与步数。
3. **GUI 与实时相机**：新增“RGB-D 连续跟踪实验”页，独立于原重建页。先支持导入、时间轴和离线回放，再接实时相机。

GUI 应显示当前帧/时间、TRACKING/LOST 状态、残差与置信度、关键帧触发原因、端到端延迟和是否超过 100 ms；提供原始 / 独立 CUDA60 / 连续细化对照、暂停逐帧与区间统计。开始前明确是否已完成 SAM3 准备；运行时锁定相冲突的模型操作。

本轮交付为数据审计和计划，尚无连续跟踪效果或速度结果。下一次实现优先完成步骤 1，依据实际失败片段再调整优化器或评估是否值得训练 refiner。
