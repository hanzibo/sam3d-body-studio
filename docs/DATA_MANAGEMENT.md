# 数据管理

第四个标签页“数据管理”统一浏览本地采集与计算产物。进入页面自动后台统计，也可手动刷新；不会加载模型或连接相机。原有数据不迁移。

下列路径相对于 Studio 应用目录，界面会显示实际绝对路径：

| 目录 | 内容 / 管理单位 |
| --- | --- |
| `outputs/rgbd/<时间>/` | 单张 RGB-D：彩色照片、米制深度/点云、内参、前背景提示、SAM3 分割、掩膜、预测、评估、对比表；整张样本一起管理 |
| `outputs/rgbd-sets/<时间>/` | 多姿态样本集：`pose_set.json`、各姿态独立样本、批量任务记录、导出对比表；整套管理 |
| `outputs/gui/<时间>/` | 一次重建 / 测速：归一化输入、请求配置、人体参数、网格、对照图和报告；整次管理 |
| `outputs/camera/<时间>/` | 第一页彩色相机照片和拍摄元数据 |
| `outputs/motions/<时间>/` | 动作录制：帧 JSONL、原始 / 平滑骨架与关节角 CSV、录制元数据 |
| `outputs/streams/` | 实时流统计摘要；未录制时不会永久保留逐帧结果 |
| `outputs/sessions/` | 模型会话配置 JSON、加载 / 预热 / 推理日志；当前会话只读 |
| `outputs/mhr-lab/<时间>/` | 新的实验室默认导出：同次 NPZ、JSON、PLY 一起管理；保存对话框仍可另选路径 |
| `outputs/` 其他子目录 | 早期测试、分析、性能验证产物，按整个目录管理 |
| `outputs/` 直接存放的文件 | 旧的实验室快照等单独条目；同名 NPZ / JSON / PLY 请同时选中 |
| 根目录 `*.log`、`Log/`、`logs/` | 早期部署 / 测试日志 |
| `camera-analysis/`、`fast-analysis/`、`community-review/` | 早期实验 / 分析产物 |

`outputs/gui/run-history.json`、`outputs/gui/desktop.log`、`outputs/yolo-config/`、`backups/` 仅供查看。源码、模型权重、TensorRT 引擎、编译缓存、Conda 环境、`assets/`、`config/` 和 `profiles/` 不在可清理范围。手动导出到其他目录的照片 / 网格 / 数据包不自动纳入；使用文件管理器自行管理。

## 使用

1. 切到“数据管理”，按类别筛选或搜索名称 / 路径，可按最近修改、占用空间从大到小 / 从小到大、类别 / 名称排序。点击“大小（逻辑）”表头也可切换大小升降序，按实际字节数比较，表头箭头显示方向。列表显示逻辑大小、文件数和最近修改时间；顶部显示所在磁盘可用空间。
2. 选择条目查看目录树和文件。展开目录后点击 JSON、CSV、日志或图片可预览。文本最多读前 256 KiB；大图有限制，NPZ、模型、网格等二进制文件只列出，不执行或反序列化。
3. “打开所在目录”或双击条目在系统文件管理器中打开。Ctrl / Shift 支持多选；右键或按钮可“移入回收站”。确认框列出数据范围和总大小，默认取消。
4. 删除只移入系统回收站。目录内照片、分割、预测和评分一并移走，不单独删除样本内部文件。回收站不可用时保留原数据并报错，不自动永久删除。**清空系统回收站后才释放磁盘空间**，这一步由用户在文件管理器完成。

采集、相机预览、倒计时、实时流、推理 / 加载、SAM3、批量任务、动作录制、实验室计算和后台对照图渲染期间禁用删除。当前打开的输入照片、结果、RGB-D 样本 / 姿态集、实验室预测及当前会话日志也受保护；可先切换到其他数据，或关闭后重启应用，再清理旧数据。确认后还会重新检查，文件操作期间阻止启动新的界面任务。

页面拒绝跟随符号链接；统计跳过链接目标。只允许删除白名单目录下的完整条目，不能输入任意路径进行清理。保护仅针对本 Studio 实例可知的任务，不扫描其他应用或另一实例的文件占用。

历史索引保留，不随物理数据删除而改写；已移走数据的详情 / 源照片链接会缺失，恢复原路径后可继续访问。RGB-D 和姿态集内部预测有独立副本，清理 `outputs/gui/` 的重复工作目录不会自动清理这些副本。若仍需跨方案对照，请保留完整原始样本 / 样本集。

大小为文件逻辑字节数，并非精确的可释放物理空间：硬链接、稀疏文件、回收站、同盘其他程序以及扫描中的变化均可能影响显示。

## 验证

```bash
python3 -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen python tests/gui_startup.py
QT_QPA_PLATFORM=offscreen python tests/data_manager_gui.py
```

单元测试覆盖完整样本分组、模型排除、只读项、活动路径保护、越界路径、符号链接和过期条目。GUI 测试仅用临时样本验证后台统计、文本 / 图片预览、筛选、任务保护、取消、实际移入回收站并恢复，以及回收站失败时保留数据；不会删除真实用户数据、加载权重或连接相机。
