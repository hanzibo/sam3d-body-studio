# Local SMPL assets (not distributed)

Obtain SMPL neutral from https://smpl.is.tue.mpg.de/ under its model license.
Place your authorized `SMPL_NEUTRAL.pkl` or numeric `SMPL_NEUTRAL.npz` here.
Do not publish the archive, PKL, converted NPZ or other derived model data.

The optional converter also needs `mhr2smpl_mapping.npz` from
https://github.com/facebookresearch/MHR/tree/main/tools/mhr_smpl_conversion/assets
under its upstream terms. See `docs/INSTALL.md`; MHR skeleton viewing does not
require these files. All files here except this README are ignored by Git.
